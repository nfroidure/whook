# @whook/mcp
> Adds an MCP server that proxies the API routes

[![GitHub license](https://img.shields.io/badge/license-MIT-blue.svg)](https://github.com/nfroidure/whook/blob/main/packages/whook-mcp/LICENSE)


[//]: # (::contents:start)

This module provides MCP capabilities to a
[Whook](https://github.com/nfroidure/whook) server !

## Usage

This module requires `@whook/authorization`.

## Setup

Install the module:

```sh
npm i @whook/mcp
```

Update the types (usually in `src/whook.d.ts`):

```diff
+import {
+   type WhookMCPServerConfig,
+   type WhookMCPHandlerConfig,
+   type WhookMCPRouteConfig,
+} from '@whook/mcp';

// ...

declare module 'application-services' {

  export interface AppConfig
    extends WhookBaseConfigs,
      // (...)
+      WhookMCPServerConfig,
+      WhookMCPHandlerConfig,
      JWTServiceConfig {}

// ...

declare module '@whook/whook' {
  export interface WhookRouteConfig
-    extends WhookBaseRouteConfig {}
+    extends WhookBaseRouteConfig,
+      WhookMCPRouteConfig {}
}

}
```

Declare the plugin into your `src/index.ts` file:

```diff

  // (...)

  // Setup your own whook plugins or avoid whook defaults by leaving it empty
  $.register(
    constant('WHOOK_PLUGINS', [
      ...WHOOK_DEFAULT_PLUGINS,
+      '@whook/mcp',
      '@whook/cors',
    ]),
  );

  // ...

```

Alternatively, you can use the HTTP router wrapper if you wish to use several
wrappers for it by cloning the [`httpRouter`](./src/services/httpRouter.ts)
service file in your project.
